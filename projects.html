FAQ на JavaScript

2026

Когда-то нужно было просто сделать раскрывающийся ответ. Конечно, всё оказалось немного интереснее.

На первый взгляд FAQ — вещь элементарная. Есть вопрос. Есть ответ. Нажал на вопрос — ответ появился.

Что может пойти не так?

Ну... почти всё.

Этот проект стал хорошей практикой работы с DOM и событиями JavaScript. Нужно было научиться находить нужный элемент, реагировать на клик, менять состояние блока и при этом не превращать страницу в склад открытых ответов.

В результате получился аккуратный FAQ, где пользователь открывает нужный вопрос, а интерфейс плавно реагирует на его действие.

Задача

Создать интерактивный блок вопросов и ответов, который будет понятен пользователю и удобен в использовании.

Решение

Использовать JavaScript для обработки кликов, управления классами и изменения состояния элементов интерфейса.

Чему научился

  • Работать с DOM
  • Находить элементы страницы
  • Обрабатывать события
  • Использовать addEventListener
  • Управлять CSS-классами через JavaScript
  • Связывать JavaScript, HTML и CSS

Запись №8

Форма обратной связи

2026

Проект, который должен был просто отправлять сообщение. А потом появился EmailJS.

Форма обратной связи — один из тех элементов сайта, на которые обычно никто не обращает внимания.

Пока она работает.

Пользователь вводит имя, оставляет email, пишет сообщение и нажимает кнопку.

А дальше начинается самое интересное: сообщение должно каким-то образом добраться до человека по ту сторону сайта.

Здесь появилась практика работы с EmailJS. Задача была вполне конкретной: сделать форму, которая действительно отправляет сообщение, а не просто красиво выглядит и после нажатия на кнопку делает вид, что всё произошло.

Задача

Создать рабочую форму обратной связи, которая позволяет пользователю отправить сообщение непосредственно с сайта.

Решение

Использовать JavaScript для обработки формы и EmailJS для передачи сообщения на электронную почту.

Чему научился

  • Работать с HTML-формами
  • Обрабатывать события формы
  • Получать данные из полей
  • Работать с EmailJS
  • Обрабатывать успешную отправку
  • Обрабатывать ошибки
